- Currency renamed to Tech$$$ (abbreviated T$).

## [1.0.0] - 2026-10-02

### Added
- Uptime Quest, built on the Packet Quest engine (3x crisp rendering, readable monospace for terminal text).
- Eight mini-games: Disk Space Panic, Password Reset Rush, Patch Tuesday, Script Commit (Claude); VM Tetris, Backup Restore Run, Group Policy Maze, Ransomware Siege (Codex).
- Sysadmin overworld: Branch Office, Help Desk, Server Closet, User's Desk, DC Castle, Server Room, Cloud Island, HQ Tower, Exec Suite, Data Center. Server racks blink in place of trees.
- Enemies: Memory Leak Blob, Zombie Processes, Expired Cert Ghost, Service Account Phantom, Snapshot Hoarder, Shadow IT Slime.
- Bosses: The Disk Hog, Count DNS-ula, The Auditor, The Blue Screen of Doom (restore-order triage plus Ransomware finale), and the Read-Only Friday surprise boss.
- Week clock, "days since last outage" sign, Remote Desktop Wand, Automation Scroll, Immutable Backup Shield, three cert tiers.
- Economy, boss phases, tips, and user quotes from Grok's design brief.
